### 🗄️ [sql_ong_ayuda_accion](https://github.com/darwinjcn/sql_ong_ayuda_accion) ⭐ Nuevo
> Sistema de base de datos relacional diseñado para optimizar las operaciones de la ONG "Ayuda en Acción". Centraliza la gestión de donadores, trazabilidad de fondos, asignación de recursos a proyectos e informes de impacto automatizados, garantizando transparencia y eficiencia en la ayuda humanitaria.

**Stack:** PostgreSQL 17 · ERD · B-Tree Indices · Materialized Views

**Funcionalidades destacadas:**
- 🔗 Trazabilidad total: desde la recepción de donaciones hasta la ejecución en campo
- 💳 Gestión multicanal: donaciones monetarias (tarjeta, transferencia, pago móvil) y en especie
- 🔍 Transparencia: vistas automatizadas para calcular el impacto financiero real de cada proyecto
- 📧 CRM de comunicación: gestión de interacciones para mantener a los donadores informados
